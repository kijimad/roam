* 言語によって異なる挙動

負の値に対する剰余をしたときの値は、プログラミング言語によって異なる。軽く試したところ2パターンあった。

Go言語。

#+begin_src go :imports fmt
  fmt.Println(-8 % 5)
  fmt.Println(8 % -5)
#+end_src

#+RESULTS:
#+begin_src
-3
3
#+end_src

C言語。

#+begin_src C :results raw
  printf("%d\n", -8 % 5);
  printf("%d\n", 8 % -5);
#+end_src

#+RESULTS:
#+begin_src
-3
3
#+end_src

Emacs Lisp。

#+begin_src emacs-lisp
  (format "%s\n%s" (number-to-string (% -8 5)) (number-to-string (% 8 -5)))
#+end_src

#+RESULTS:
#+begin_src
-3
3
#+end_src

Python。

#+begin_src python :results output
  print(-8 % 5)
  print(8 % -5)
#+end_src

#+RESULTS:
#+begin_src
2
-2
#+end_src

Ruby。

#+begin_src ruby
  sprintf("%d\n%d", -8 % 5, 8 % -5)
#+end_src

#+RESULTS:
#+begin_src
2
-2
#+end_src
