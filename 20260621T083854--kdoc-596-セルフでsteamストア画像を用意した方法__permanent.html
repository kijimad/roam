概要

Steamのストア画像は、サイズや指定の違う数種類の画像を用意する必要があって大変である。自分で用意した。

  1. Claude Code に丸投げすると、まったく思い描いた感じにならなかった
  2. Stable diffusion でロゴ、背景、前景を分けて画像を生成した。同じプロンプトで大量に生成して、Claude Code に選別と、自分の候補選択を数回繰り返した
  3. バリエーションごとに画像を配置するスクリプトを作成した
