KDOC 638: 配列の定数インデックスはビルド時に検証される

概要

Go で定数インデックスで配列にアクセスすると、ビルド時にチェックされる。 

set -e
d=$(mktemp -d)
cat > "$d/go.mod" <<'EOF'
module demo

go 1.26.0
EOF
cat > "$d/bce.go" <<'EOF'
package demo

func main() {
var a [3]int
_ = a[5]
}
EOF

cd "$d"
go build . 2>&1

./bce.go:5:7: invalid argument: index 5 out of bounds [0:3]

関連

抽象。

  • 実行時に起きる誤りの一部は、値が事前にわかれば作る段階で見つけられる
