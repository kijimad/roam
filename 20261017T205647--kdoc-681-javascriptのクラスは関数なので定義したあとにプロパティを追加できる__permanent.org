* 概要

JavaScriptのクラスは特別な関数で、関数はオブジェクトである。そのため、定義したあとのクラスにもふつうのオブジェクトと同じようにプロパティを追加できる。追加したプロパティはクラス自身に付き、 ~static~ で定義したものと同じくインスタンスからは見えない。

#+begin_quote
クラスは実際には「特別な関数」であり、(後略)

[[https://developer.mozilla.org/ja/docs/Web/JavaScript/Reference/Classes][クラス - MDN]]
#+end_quote

#+begin_src js :results output
  class MyClass {}
  MyClass.key = "value";
  console.log(typeof MyClass, MyClass.key);
  console.log(new MyClass().key);
#+end_src

#+RESULTS:
#+begin_src
function value
undefined
#+end_src

~typeof~ が ~function~ を返すのは、クラスが ~[[Call]]~ を持つオブジェクトだからである。

#+begin_quote
If val has a ~[[Call]]~ internal slot, return "function".

[[https://262.ecma-international.org/16.0/#sec-typeof-operator-runtime-semantics-evaluation][ECMAScript 2025 Language Specification 13.5.3.1]]
#+end_quote
