概要

Go の標準ライブラリ testing には、アロケーション回数を計測する関数がある。たとえば opentelemetry-go のテストは、アロケーション回数が1回以下であることを確かめている。 

https://github.com/kijimad/opentelemetry-go/blob/d36fabe359fbf36bc9abd23de663df10db56cb0d/sdk/log/internal/attrnorm/dedup_test.go#L344-L349

allocs := testing.AllocsPerRun(1000, func() {
	got, depthLimited, deduplicated = ValueDedupLimitDepth(value, 64)
})
if allocs > 1 {
	t.Fatalf("ValueDedupLimitDepth() allocations = %v, want at most 1", allocs)
}

アロケーション回数は実行速度とは違って環境でぶれにくく、テストで固定して検証しやすい。testing は、1回空回ししてから測り、測る間は GOMAXPROCS を1にして、ぶれの元を除いている。 

https://github.com/golang/go/blob/8fc7e76411ed6db7a351db1e4be762cdc5350de5/src/testing/allocs.go#L14-L19

// To compute the number of allocations, the function will first be run once as
// a warm-up. The average number of allocations over the specified number of
// runs will then be measured and returned.
//
// AllocsPerRun sets [runtime.GOMAXPROCS] to 1 during its measurement and will restore
// it before returning.
