* 概要

Emacs Lispのシンボルは、変数としての値を入れる値セルと、関数を入れる関数セルを別々に持つ。そのため同じ名前で、 ~setq~ で値を、 ~defun~ で関数を両方定義できる。関数そのものには名前がなく、関数セルに関数を持つシンボルが関数の名前になる。 ~defun~ はシンボルの関数セルに関数を入れているだけである。

#+begin_src shell :results output
  etc=$(emacs -Q --batch --eval '(princ data-directory)')
  info -f "$etc/../../../info/elisp.info.gz" -n 'Symbol Components' -o - | sed -n '35,36p' | sed 's/  \*Note$//'
  echo
  info -f "$etc/../../../info/elisp.info.gz" -n 'Function Names' -o - | sed -n '6,10p'
#+end_src

#+begin_src emacs-lisp
  (setq kd-foo 1)
  (defun kd-foo () 2)
  (format "変数として: %S、関数として: %S" kd-foo (kd-foo))
