概要

TypeScriptがJavaScriptに変換される様子を見る。 

cat << 'EOF' | npx -y esbuild --loader=ts --format=cjs 2>&1
/* 変数定義 */
let color: string = "red";

/* 関数定義と呼び出し */
function greet1(name: string) {}
greet1("hello")

/* 三項演算子 */
1 ? "a" : "b"

/* 型定義 */
type animal = "dog" | "cat"

EOF

let color = "red";
function greet1(name) {
}
greet1("hello");
1 ? "a" : "b";

関連

抽象。

  • 検査のためだけの情報は、変換後の実行物には残らない

関連。

  • 疑問: KDOC 382: JavaScriptにトランスパイルするのはなぜか?。JavaScriptへ変換してから実行する手間を、なぜかけるのかという疑問
  • 補足: KDOC 388: 『仕事ですぐに使えるTypeScript』。型の情報が実行時には使われないこと
  • 対比: KDOC 524: JSXは変換するとReact.createElementの呼び出しになる。同じ変換でも、型の記載は消えるのに対し、JSXは実行時に動く関数呼び出しに置き換わって残る
