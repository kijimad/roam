概要

RDS Performance Insights の値は何に由来しているのだろう、と考えた。PostgreSQL に同梱された拡張 pg_stat_statements の値を集計しているように見える。

Performance Insights は、SQL 呼び出しごとおよびクエリが実行中の 1 秒ごとに SQL 統計を収集します。

(略)

SQL ダイジェストの統計を表示するには、RDS PostgreSQL が pg_stat_statements ライブラリをロードする必要があります。

(略)

これらのメトリクスの詳細については、PostgreSQL ドキュメントの「pg_stat_statements」を参照してください。

RDS PostgreSQL での SQL 統計 - Amazon Relational Database Service

いっぽうで DB Load (AAS) は pg_stat_statements になく、すべてそこから集計しているわけではない。

毎秒、Database Insights は、クエリを同時に実行するセッションの数をサンプリングします。Database Insights は、アクティブなセッションごとに以下のデータを収集します。

  • SQL ステートメント
  • セッション状態 (CPU で実行中または待機中)
  • ホスト
  • SQL を実行しているユーザー
