概要

余りがマイナスになるか正の数になるかの方式の違いは “modulus”, “reminder” という。プログラミング言語によってどちらを採用しているか違う。 

return -10 % 3

2

import "fmt"
func main() {
      fmt.Println(-10 % 3)
}
