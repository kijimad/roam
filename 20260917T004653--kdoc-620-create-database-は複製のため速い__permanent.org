* 概要

高速に複数の Database を用意する必要に迫られた。

1. マスタ DB を作成する ~CREATE DATABASE {マスタDB}~
2. マスタをマイグレーションする
3. マスタDBを元にテスト用DBを作成する。 ~CREATE DATABASE {テスト用DB} TEMPLATE {マスタDB}~

CREATE DATABASE は複製であって、空 DB をマイグレーションするより高速である。

#+begin_quote
By default, the new database will be created by cloning the standard system database template1. A different template can be specified by writing TEMPLATE name.

[[https://www.postgresql.org/docs/16/sql-createdatabase.html][PostgreSQL: Documentation: 16: CREATE DATABASE]]
#+end_quote
