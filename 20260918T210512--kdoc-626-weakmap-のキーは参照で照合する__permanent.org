* 概要

WeakMap のキーは参照で照合するので、値が同じであっても区別される。

#+begin_src js :results output
  const wm = new WeakMap();

  const keyObject1 = {"this is": "key object"};
  const keyObject2 = {"this is": "key object"};

  wm.set(keyObject1, "save1");
  wm.set(keyObject2, "save2");

  console.log(wm.get(keyObject1));
  console.log(wm.get(keyObject2));
#+end_src

#+RESULTS:
#+begin_src
save1
save2
#+end_src

#+begin_quote
キーの等価性
通常の Map と同様に、値の等価性は SameValueZero アルゴリズムに基づきます。これは === 演算子と同じです。WeakMap がオブジェクトとシンボルのキーしか保持できないためです。つまり、オブジェクトキーの場合、等価性はオブジェクトが同一のものであるかに基づきます。これらは値ではなく参照によって比較されます。

[[https://developer.mozilla.org/ja/docs/Web/JavaScript/Reference/Global_Objects/WeakMap][WeakMap - JavaScript | MDN]]
#+end_quote
