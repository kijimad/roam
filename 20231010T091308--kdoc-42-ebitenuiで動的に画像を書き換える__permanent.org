EbitenUIはゲームエンジンEbitengineのUIライブラリである。クリックなどのイベントに応じて動的にラベルを切り替える方法がわからなかったので、コードを読んで把握した方法を書く。

結論としては、UIのイベントハンドラに自身のフィールドを書き換える無名関数を登録すればよい。

#+caption: ボタンをクリックするたびにラベルを現在時刻に変更する例
#+begin_src go
  makeLabel := func() string {
          t := time.Now()
          return t.Format("03:04:05")
  }
  button := newButton() // newButton()は *widget.Button を返す関数
  button.ClickedEvent.AddHandler(func(args interface{}) {
          button.Text().Label = makeLabel()
  })
#+end_src
