* 概要

NaNが含まれる可能性のある計算があると、数値比較によるガードをすり抜けることがある。

- [[https://github.com/open-telemetry/opentelemetry-go/pull/8812#pullrequestreview-5012599369][fix(trace): handle NaN sampling fraction deterministically in TraceIDRatioBased by waterWang · Pull Request #8812 · open-telemetry/opentelemetry-go]]

NaNとの数値比較は ~!=~ 以外すべて false になり、条件をすり抜けてしまう。

実行して確認する。

#+caption: math.NaN() と比較する
#+begin_src go
  import (
    "math"
    "fmt"
  )

  func main() {
    fmt.Println(math.NaN())
    fmt.Println(math.NaN() > 1)
    fmt.Println(math.NaN() < 1)
    fmt.Println(math.NaN() >= 1)
    fmt.Println(math.NaN() <= 1)
    fmt.Println(math.NaN() == 1)
    fmt.Println(math.NaN() != 1)
  }
#+end_src

#+RESULTS:
#+begin_src
NaN
false
false
false
false
false
true
#+end_src

定義を見る。この挙動は IEEE 754 で定義されているとのこと。

https://github.com/golang/go/blob/8fc7e76411ed6db7a351db1e4be762cdc5350de5/src/math/bits.go#L30-L31
#+end_src
