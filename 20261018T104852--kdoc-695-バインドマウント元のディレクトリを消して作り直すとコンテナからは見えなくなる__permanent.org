* 概要

バインドマウントは、パスではなく、マウントした時点のディレクトリそのものを別の場所に見せる。ホスト側でそのディレクトリを消して同じ名前で作り直しても、コンテナは消された古いディレクトリを見続けるので、中身は消えたままに見える。コンテナを再起動すると、新しいディレクトリがマウントし直される。

#+begin_src shell :results output
  dir=$(mktemp -d); mkdir "$dir/src"; echo old > "$dir/src/a"
  docker run -d --rm --name bm -v "$dir/src":/mnt busybox sleep 60 >/dev/null
  echo "マウント直後: $(docker exec bm cat /mnt/a 2>&1)"
  rm -rf "$dir/src"; mkdir "$dir/src"; echo new > "$dir/src/a"
  echo "作り直した後: $(docker exec bm cat /mnt/a 2>&1)"
  docker restart bm >/dev/null
  echo "再起動した後: $(docker exec bm cat /mnt/a 2>&1)"
  docker rm -f bm >/dev/null; rm -rf "$dir"
#+end_src

#+RESULTS:
#+begin_src
マウント直後: old
作り直した後: cat: can't open '/mnt/a': No such file or directory
再起動した後: new
#+end_src
