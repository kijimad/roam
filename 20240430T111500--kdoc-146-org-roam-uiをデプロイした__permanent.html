概要

org-roam-uiはOrg-roamをいい感じにグラフィカル表示するライブラリである。最近orgファイルをorg-roam-uiに静的ビルドしてGitHub Pagesに公開するGitHub Actionsの workflowが作成されたようなので、解説記事を参考に設定して見られるようにした。

デプロイする

GitHub ActionsでGitHub Pagesにorg-roam-uiを公開するで解説されている。手元で動かすのはEmacsから簡単にできるのだが、静的ビルドするのは煩雑なやり方が必要で、あきらめた記憶がある。簡単にできるとありがたい1。

デプロイを設定したリポジトリ。

  • kijimaD/roam-ui

関連

抽象。

  • 手元でしか動かせなかったものを、自動の手順で静的に公開する
  • 手軽に使える分、変更の自由度は低い

関連。

  • 動機: KDOC 36: 『TAKE NOTES!』。関連を可視化できるとメモする参考になる
  • 補足: KDOC 98: org-roam-node-findでエントリが出なくなったときの直し方。org-roamのデータベースが、ファイルから作り直せる索引であることがわかる

Footnotes:

1

いまのところ、サクッとできて便利な分、カスタマイズはほぼできない。org-roamのデータベースをチェックインしないと使えない。現状ドキュメントはワークフロー上でデータベースをビルドする形式でやっている(データベースファイルをチェックインしない)のでそれに合わせたかったのだが。
