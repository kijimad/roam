* 概要

遅延関数は、周囲の関数が戻り値を返した後に LIFO の順序で実行される。

[[https://go.dev/blog/defer-panic-and-recover][Defer, Panic, and Recover - The Go Programming Language]]

#+begin_src go
  import "fmt"

  func main() {
      for i := 0; i < 4; i++ {
          defer fmt.Print(i)
      }
  }
#+end_src

#+RESULTS:
#+begin_src
3210
#+end_src

defer 実行時でなく、 defer 文評価時 ~i~ が確定する。

#+begin_example
                    ループでの実行順序   deferの実行順序
defer fmt.Print(0)        1                  4
defer fmt.Print(1)        2                  3
defer fmt.Print(2)        3                  2
defer fmt.Print(3)        4                  1
#+end_example
