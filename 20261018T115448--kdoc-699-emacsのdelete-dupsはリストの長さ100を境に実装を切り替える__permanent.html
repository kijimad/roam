概要

Emacs Lispでリストから重複を除く delete-dups は、リストの長さで実装を切り替える。100より長いときはハッシュテーブルに出てきた要素を記録しながら1回なめる。100以下のときは、先頭から1つずつ取り、残りから同じ要素を delete で消していく。

delete で消すやり方は要素ごとに残り全体をなめるので、手間が長さの2乗で増える。ハッシュテーブルを使うやり方は1回なめるだけで済むが、表を作る手間がかかる。長いリストで遅かったため、100を超えたらハッシュテーブルを使うようにした。100という値の根拠は書かれていない。

When there are more than 100 candidates, use a hash table. This can result in ~500 times speed-up for typical collections of size 5000, like that of `load-library’.

lisp/subr.el (delete-dups): Use a hash table (2015-05-06) 

https://github.com/emacs-mirror/emacs/blob/a360712c9d272d950d8d8255ef74570f7e90b7d9/lisp/subr.el#L929-L943

(let ((l (length list)))
  (if (> l 100)
      (let ((hash (make-hash-table :test #'equal :size l))
            (tail list) retail)
        (puthash (car list) t hash)
        (while (setq retail (cdr tail))
          (let ((elt (car retail)))
            (if (gethash elt hash)
                (setcdr tail (cdr retail))
              (puthash elt t hash)
              (setq tail retail)))))
    (let ((tail list))
      (while tail
        (setcdr tail (delete (car tail) (cdr tail)))
        (setq tail (cdr tail))))))
