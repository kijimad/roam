* 概要

ASCII の DEL(削除)の文字コードが 0x7F、つまり7ビットがすべて1なのは、紙テープで文字を消すためだったという。紙テープは1文字を穴の有無で表す。間違えて穴を開けた文字は、穴を塞げないが、残りの穴もすべて開ければ「すべて1」になる。この全部が1の文字は無視する、と決めておけば、間違えた文字を消したことにできる。

If a character was punched erroneously, punching out all seven bits caused this position to be ignored or deleted.
