概要

コーディング問題に、数値を桁ごとに処理せよ、というものがある。さっと出てこなかったのでメモしておく。 

import "fmt"
func main() {
        for _, r := range "12345" {
                c := int(r - '0')
                fmt.Println(c)
        }
}

流れ。

  1. 入力文字列(数字)をrune、つまりUnicodeコードポイントに分割する
  2. 1文字ごとにベースのコードポイント’0’でオフセットを取って、コードポイントを数値に変換する。数字のコードポイントは連番で並んでいる
  3. 得られた数値を使う

関連

抽象。

  • 記号が連番で並ぶことを利用して、差を取るだけで値に変換する

関連。

  • 類推: KDOC 347: 小文字のruneに’A’-’a’を足すと大文字に変換できる。類似した、コードポイントを使ったトリック。数字、小文字、大文字ごとでコードポイントが連番なのでトリックが使える
