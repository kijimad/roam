* 概要

Rubyでは ~false~ と ~nil~ 以外はすべて真なので、文字列の ~"false"~ も真になる。

Railsの ~ActiveModel::Type::Boolean~ は、フォームやDBから文字列で来た真偽値を変換する。booleanのカラムに代入した値は、Active Recordがこの型を使って自動的に変換するので、ふだんは自分で ~cast~ を呼ばない。決まった一覧にある値( ~"false"~ ・ ~"0"~ ・ ~"f"~ ・ ~"off"~ など)を ~false~ にし、空文字列を ~nil~ にし、一覧にない値はすべて ~true~ にする。そのため ~"no"~ は ~true~ になる。一覧には ~"false"~ と ~"FALSE"~ はあるが ~"False"~ はないので、 ~"False"~ も ~true~ になる。
