* 概要

- [[https://github.com/prisma/orm/issues/12735][Support for row-level security (RLS) · Issue #12735 · prisma/orm]]

Prisma は RLS を公式にサポートしていない。リクエストなど、あるコンテキスト内で同じコネクションを再利用することを保証できないので、毎回トランザクションを貼ってコネクションを排他的に使うしかない。

* 関連

抽象。

- 状態を持つ資源を同じ相手が使い続ける保証がないと、毎回占有するしかなく効率が落ちる
