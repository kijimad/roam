* 概要

JavaScriptの ~const~ の宣言はスコープに入った時点で作られ、宣言の行を実行するまでは参照できない(一時的デッドゾーン)。そのため宣言より前では、外側に同名の変数があっても読めず ~ReferenceError~ になる。

#+begin_src js :results output
  const x = 1;
  {
    try {
      console.log(x);
    } catch (e) {
      console.log(`${e.name}: ${e.message}`);
    }
    const x = 2;
  }
#+end_src

#+RESULTS:
#+begin_src
ReferenceError: Cannot access 'x' before initialization
#+end_src

#+begin_quote
The variables are created when their containing Environment Record is instantiated but may not be accessed in any way until the variable's LexicalBinding is evaluated.

#+end_quote
