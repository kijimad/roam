* 概要

Emacsでマークを置くとリージョンが光るのは、Transient Mark modeが有効だからである。これが既定で有効になったのはEmacs 23.1からである。それより前は既定ではリージョンが画面に出ず、マークの位置を覚えておく必要があった。

#+begin_src shell :results output
  etc=$(emacs -Q --batch --eval '(princ data-directory)')
  grep -n -E '^\* Editing Changes in Emacs 23\.1$|Transient Mark mode is now on by default' "$etc/NEWS.23"
  info -f "$etc/../../../info/emacs.info.gz" -n 'Disabled Transient Mark' -o - | sed -n '13,15p'
#+end_src
