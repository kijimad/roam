* 概要

DBLoad は平均アクティブセッション数(AAS)である。実行中というだけで、DBLoadが高くてもDB の CPU負荷は低い、ということがありうる。

アクティブはCPU実行中だけでなく待機(ロック/IO 等の wait イベント)も含む。だから待機主体なら DBLoad 高でも CPU 負荷は低くなる。

DBLoad

The number of active sessions for the database. Typically, you want the data for the average number of active sessions. In Performance Insights, this data is queried as db.load.avg.

[[https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/USER_PerfInsights.Cloudwatch.html][Amazon CloudWatch metrics for Amazon RDS Performance Insights - Amazon Relational Database Service]]
