#+title:      KDOC 46: Goの宣言構文は左から右に読めるようCから変えられた
#+date:       [2023-10-14 Sat 17:14]
#+filetags:   :permanent:
#+identifier: 20231014T171444

Goの宣言構文は、C言語と異なっている。Goの設計者は、C言語でのわかりにくさを改善するためにGoでの宣言構文を採用したという。C言語のネストした型宣言は順番通りに読めずわかりにくい。

表現しようとしている型の図。

[[file:./images/20231014-pointer.drawio.svg]]

#+caption: Cの宣言構文。ポインタ型で、ポインタが指しているのはintを返す関数型
#+begin_src C
int (*x) () // => * func() int
#+end_src

Goはそのまま左から右に読める。

#+caption: Goの宣言構文。ポインタ型で、ポインタが指しているのはintを返す関数型
#+begin_src go
*func() int
#+end_src

* 関連

抽象。

- 先行する設計の問題点を知ると、後発の設計の決定理由がわかる
