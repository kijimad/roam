概要

useradd -m や adduser でユーザを作ると、ホームディレクトリに /etc/skel の中身がコピーされる。新しいユーザに最初から置いておきたい設定ファイルは、 /etc/skel に入れておけばよい。 

dpkg-query -W -f='${Package} ${Version}\n' passwd adduser
MANWIDTH=80 man 8 useradd | grep -A2 'The skeleton directory, which'
MANWIDTH=80 man 5 adduser.conf | grep -A1 -E '^ +SKEL +The'

adduser 3.137ubuntu1
passwd 1:4.13+dfsg1-4ubuntu3.2
         The skeleton directory, which contains files  and  directories  to  be
         copied  in  the user's home directory, when the home directory is cre‐
         ated by useradd.
     SKEL   The  directory from which skeletal user configuration files will be
            copied.  Defaults to /etc/skel.

確認する。 

ls -A /etc/skel

.bash_logout
.bashrc
.config
.gtkrc-2.0
.gtkrc-xfce
.local
.profile
